Usuário legítimo

Navegador

Este botão faz uma requisição HTTP real ao serviço limitado. O tempo exibido é medido pelo navegador, do envio até a resposta.

Nenhuma tentativa manual nesta sessão.

Durante o cenário, uma sonda legítima automática também acessa o serviço a cada segundo. Ela fornece amostras comparáveis entre execuções com e sem proteção.

Transparência metodológica

Como interpretar os números

Sucesso

Resposta HTTP 200 emitida após ocupar uma vaga de processamento.

Rejeitado

Resposta HTTP 429 emitida pelo limitador de taxa daquele cliente.

Falha de disponibilidade

HTTP 503 por capacidade esgotada ou erro de transporte sem resposta.

Latência

Tempo real do handler no servidor para respostas 200; p95 é o percentil 95 da amostra.

Distribuição simulada

Clientes virtuais são threads locais identificadas no cabeçalho do laboratório, não máquinas remotas.

Processamento sintético

A pausa de {{ limites.processamento_simulado_ms }} ms representa trabalho limitado; não é uma medição de hardware.
